# 数据流与通信协议

## 1. 概述

RubyFPV 系统的数据流分为上行链路（地面站→机载端）和下行链路（机载端→地面站）。系统支持多种遥测协议和RC传输方式。

## 3. 上行链路（地面站→机载端）

### 3.1 上行数据类型

| 数据类型 | PACKET_TYPE | 说明 |
|----------|-------------|------|
| RC数据 | `PACKET_TYPE_RC_DATA` (1) | RC遥控通道数据 |
| 命令数据 | `PACKET_TYPE_COMMAND` (2) | 控制命令 |
| 遥测请求 | `PACKET_TYPE_TELEMETRY_REQUEST` (3) | 遥测数据请求 |
| 配置数据 | `PACKET_TYPE_CONFIG` (4) | 配置同步 |
| 心跳包 | `PACKET_TYPE_HEARTBEAT` (5) | 连接心跳 |

### 3.3 RC数据结构

```c
// RC通道帧结构
typedef struct
{
   u32 uFrameIndex;              // 帧序号
   u32 uTimeMs;                  // 时间戳 (ms)
   u16 uRCChannels[MAX_RC_CHANNELS];  // RC通道值数组
   
   // 通道值范围:
   // - PWM: 1000-2000 (中点1500)
   // - SBUS: 0-2047 (中点1024)
   
} RC_CHANNELS_FRAME;

// RC数据包
typedef struct
{
   u8 packet_type;               // PACKET_TYPE_RC_DATA
   u8 flags;                     // 标志位
   u16 frame_index;              // 帧序号
   u32 timestamp;                // 时间戳
   u8 channel_count;             // 通道数量
   u8 channel_data[];            // 通道数据 (压缩格式)
   
} RC_DATA_PACKET;
```

| 高速 | 100 Hz | 10ms间隔 |
| 低速 | 25 Hz | 40ms间隔 |

## 5. 遥测协议

### 5.1 MAVLink协议

MAVLink (Micro Air Vehicle Link) 是标准的无人机通信协议。

#### MAVLink消息类型

| 消息ID | 消息名称 | 说明 |
|--------|----------|------|
| 0 | HEARTBEAT | 心跳消息 |
| 1 | SYS_STATUS | 系统状态 |
| 24 | GPS_RAW_INT | GPS原始数据 |
| 27 | RAW_IMU | IMU原始数据 |
| 29 | SCALED_PRESSURE | 气压数据 |
| 30 | ATTITUDE | 姿态数据 |
| 31 | LOCAL_POSITION_NED | 本地位置 |
| 32 | GLOBAL_POSITION_INT | 全球位置 |
| 33 | RC_CHANNELS_RAW | RC通道原始 |
| 74 | VFR_HUD | VFR HUD数据 |

#### MAVLink消息结构

```c
// MAVLink消息头
typedef struct
{
   u8 magic;          // 0xFE (起始标志)
   u8 length;         // 数据长度
   u8 seq;            // 序列号
   u8 sysid;          // 系统ID
   u8 compid;         // 组件ID
   u8 msgid;          // 消息ID
   u8 payload[256];   // 数据负载
   u16 checksum;      // 校验和
   
} MAVLINK_MESSAGE;
```

#### MAVLink数据解析

```c
// 姿态数据 (ATTITUDE)
typedef struct
{
   u32 time_boot_ms;    // 启动时间 (ms)
   float roll;          // 横滚角 (rad)
   float pitch;         // 俯仰角 (rad)
   float yaw;           // 航向角 (rad)
   float rollspeed;     // 横滚速度 (rad/s)
   float pitchspeed;    // 俯仰速度 (rad/s)
   float yawspeed;      // 航向速度 (rad/s)
   
} mavlink_attitude_t;

// GPS数据 (GPS_RAW_INT)
typedef struct
{
   u64 time_usec;       // 时间 (us)
   u8 fix_type;         // 定位类型
   s32 lat;             // 纬度 (1E-7 deg)
   s32 lon;             // 经度 (1E-7 deg)
   s32 alt;             // 高度 (mm)
   u16 eph;             // 水平精度
   u16 epv;             // 垂直精度
```

## 7. FEC编码

### 7.1 FEC概述

FEC (Forward Error Correction) 前向纠错编码用于提高数据传输可靠性。

### 7.2 FEC参数

```c
// FEC参数结构
typedef struct
{
   u8 k;              // 数据块数量
   u8 n;              // 总块数量 (数据块 + FEC块)
   u8 block_size;     // 每块大小
   
} FEC_PARAMETERS;

// FEC块结构
typedef struct
{
   u32 block_index;   // 块序号
   u32 total_blocks;  // 总块数
   u32 fec_k;         // FEC K参数
   u32 fec_n;         // FEC N参数
   u8 block_data[];   // 块数据
   
} FEC_BLOCK;
```

### 7.3 FEC编码流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                        FEC编码流程                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. 数据分割                                                        │
│     │                                                               │
│     │  原始数据                                                     │
│     │     │                                                         │
│     │     ├─► 分割为 K 个数据块                                     │
│     │     │     Block 0, Block 1, ..., Block K-1                   │
│     │     │                                                         │
│     │     └─────────────────────────────────────────────────────   │
│     │                                                               │
│     ▼                                                               │
│  2. FEC计算                                                         │
│     │                                                               │
│     │  使用 Reed-Solomon 算法                                       │
│     │     │                                                         │
│     │     ├─► 计算 N-K 个FEC冗余块                                  │
│     │     │     FEC Block K, ..., FEC Block N-1                    │
│     │     │                                                         │
│     │     └─────────────────────────────────────────────────────   │
│     │                                                               │
│     ▼                                                               │
│  3. 块发送                                                          │
│     │                                                               │
│     │  发送所有 N 个块                                              │
│     │     │                                                         │
│     │     ├─► 数据块 (K个)                                          │
│     │     ├─► FEC块 (N-K个)                                         │
│     │     │                                                         │
│     │     └─────────────────────────────────────────────────────   │
│     │                                                               │
│     ▼                                                               │
│  4. 接收端解码                                                      │
│     │                                                               │
│     │  接收部分块                                                   │
│     │     │                                                         │
│     │     ├─► 只要收到 K 个块即可恢复原始数据                       │
│     │     │     - 可以是任意 K 个块                                 │
│     │     │     - 数据块或FEC块都可以                               │
│     │     │                                                         │
│     │     └─────────────────────────────────────────────────────   │
│     │                                                               │
│     ▼                                                               │
│  5. 数据恢复                                                        │
│     │                                                               │
│     │  Reed-Solomon 解码                                           │
│     │     │                                                         │
│     │     ├─► 恢复丢失的块                                          │
│     │     ├─► 重组原始数据                                          │
│     │     │                                                         │
│     │     └─────────────────────────────────────────────────────   │
│     │                                                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 7.4 FEC配置示例

| 数据类型 | FEC K | FEC N | FEC比例 | 说明 |
|----------|-------|-------|---------|------|
| RC数据 | 4 | 8 | 50% | 高冗余，确保RC可靠 |
| 视频I帧 | 8 | 12 | 33% | 中冗余，关键帧保护 |
| 视频P帧 | 12 | 16 | 25% | 低冗余，节省带宽 |
| 遥测数据 | 6 | 10 | 40% | 中高冗余 |
