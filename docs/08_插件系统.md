# 插件系统

## 1. 模块概述

RubyFPV 提供插件系统，允许第三方开发者扩展系统功能。插件分为两类：
- **核心插件 (r_plugins_core)**: 系统级功能扩展
- **OSD插件 (r_plugins_osd)**: OSD显示功能扩展

### 1.1 插件目录结构

```
code/
├── r_plugins_core/           # 核心插件
│   ├── Makefile
│   └── plugin_core_example.cpp  # 核心插件示例
│
├── r_plugins_osd/            # OSD插件
│   ├── Makefile
│   ├── ruby_plugins_common.h/cpp  # OSD插件公共代码
│   ├── my_plugin_source.cpp       # 用户插件模板
│   ├── ruby_plugin_gauge_ahi.cpp  # AHI仪表插件
│   ├── ruby_plugin_gauge_altitude.cpp  # 高度仪表插件
│   ├── ruby_plugin_gauge_heading.cpp   # 航向仪表插件
│   ├── ruby_plugin_gauge_speed.cpp     # 速度仪表插件
│   └── ruby_plugin_osd_ahi.cpp          # OSD AHI插件
│
├── test_plugin/              # 测试插件
│
└── base/
    ├── core_plugins_settings.h/c  # 核心插件设置
    └── plugins_settings.h/cpp     # 插件设置
```

## 2. 核心插件 (r_plugins_core)

### 2.1 核心插件概述

核心插件提供系统级功能扩展，可以：
- 访问系统底层功能
- 扩展通信协议
- 添加自定义数据处理
- 扩展硬件支持

### 2.2 核心插件设置结构

```c
#define MAX_CORE_PLUGINS_COUNT 7

typedef struct
{
   void* pLibrary;                    // 动态库指针
   int (*pFunctionCoreInit)(u32, u32);    // 初始化函数
   void (*pFunctionCoreUninit)(void);      // 清理函数
   int (*pFunctionCoreGetVersion)(void);   // 版本获取函数
   u32 (*pFunctionCoreRequestCapab)(void); // 能力请求函数
   const char* (*pFunctionCoreGetName)(void);  // 名称获取函数
   const char* (*pFunctionCoreGetUID)(void);    // UID获取函数
   
   char szFile[256];                  // 插件文件路径
   char szName[128];                  // 插件名称
   char szGUID[128];                  // 插件GUID

} CorePluginRuntimeInfo;

typedef struct
{
   char szName[64];                   // 插件名称
   char szGUID[32];                   // 插件GUID
   int iEnabled;                      // 是否启用
   int iVersion;                      // 插件版本
   u32 uRequestedCapabilities;        // 请求的能力
   u32 uAllocatedCapabilities;        // 分配的能力
} CorePluginSettings;
```

### 2.3 核心插件函数接口

```c

// 插件信息查询

char* get_CorePluginName(int iPluginIndex);

```

## 3. OSD插件 (r_plugins_osd)

### 3.1 OSD插件概述

OSD插件用于扩展屏幕叠加显示功能：
- 自定义仪表盘
- 自定义数据显示
- 自定义图形元素
- 自定义告警显示

### 3.2 OSD插件文件列表

| 文件 | 功能描述 |
|------|----------|
| `ruby_plugins_common.h/cpp` | OSD插件公共代码 |
| `my_plugin_source.cpp` | 用户插件开发模板 |
| `ruby_plugin_gauge_ahi.cpp` | 人工地平仪仪表插件 |
| `ruby_plugin_gauge_altitude.cpp` | 高度仪表插件 |
| `ruby_plugin_gauge_heading.cpp` | 航向仪表插件 |
| `ruby_plugin_gauge_speed.cpp` | 速度仪表插件 |
| `ruby_plugin_osd_ahi.cpp` | OSD人工地平仪插件 |

### 3.3 OSD插件公共代码

`ruby_plugins_common.h` 提供OSD插件的公共功能：
- 插件注册

## 5. 插件能力系统

### 5.1 能力标志

插件通过能力标志请求系统资源：

```c
// 能力标志定义 (示例)
#define PLUGIN_CAPABILITY_RADIO_ACCESS    (1 << 0)   // 无线电访问
#define PLUGIN_CAPABILITY_VIDEO_ACCESS    (1 << 1)   // 视频访问
#define PLUGIN_CAPABILITY_TELEMETRY_ACCESS (1 << 2)  // 遥测访问
#define PLUGIN_CAPABILITY_RC_ACCESS       (1 << 3)   // RC访问
#define PLUGIN_CAPABILITY_RENDER_ACCESS   (1 << 4)   // 渲染访问
#define PLUGIN_CAPABILITY_FILE_ACCESS     (1 << 5)   // 文件访问
#define PLUGIN_CAPABILITY_NETWORK_ACCESS  (1 << 6)   // 网络访问
```

## 7. 插件开发指南

### 7.1 开发步骤

1. **创建插件源文件**
   - 复制 `my_plugin_source.cpp` 或 `plugin_core_example.cpp`
   - 修改插件名称和UID

2. **实现必要函数**
   - 初始化函数
   - 清理函数
   - 版本/名称/UID函数
   - 能力请求函数 (核心插件)

3. **实现插件功能**
   - 根据插件类型实现具体功能
   - OSD插件实现渲染函数
   - 核心插件实现数据处理函数

4. **编译插件**
   - 使用提供的 Makefile
   - 生成动态库文件 (.so/.dll)

5. **安装插件**
   - 将插件文件放到插件目录
   - 重启系统加载插件

### 7.2 插件命名规范

- **名称**: 描述性名称，如 "My OSD Plugin"
- **UID**: 唯一标识符，格式: `plugin_type_name_version`
- **版本**: 整数版本号

### 7.3 插件安全考虑

- 插件运行在系统进程中
- 需要谨慎处理内存和资源
- 避免阻塞操作
- 正确处理错误情况

## 9. 插件示例

// ruby_plugin_gauge_altitude.cpp

#include "ruby_plugins_common.h"
#include "../renderer/render_engine.h"

static const char* PLUGIN_NAME = "Altitude Gauge";
static const char* PLUGIN_UID = "gauge_altitude_001";

// 渲染高度仪表
void plugin_osd_render_altitude_gauge(float xPos, float yPos, float fScale)
{
    // 获取当前高度
    float altitude = get_current_altitude();
    
    // 设置颜色
    double color[] = {1.0, 1.0, 1.0, 1.0};  // 白色
    render_engine->setFill(color);
    
    // 绘制仪表背景
    render_engine->fillCircle(xPos, yPos, 50 * fScale);
    
    // 绘制高度数值
    char szAlt[32];
    sprintf(szAlt, "%.1f m", altitude);
    render_engine->drawText(xPos, yPos + 20 * fScale, FONT_ID_MEDIUM, szAlt);
    
    // 绘制高度趋势指示
    // ...
}

{
    return PLUGIN_NAME;
}

{
    return PLUGIN_UID;
}
