# 硬件平台适配

## 1. 概述

RubyFPV 支持多种硬件平台，通过平台适配层实现跨平台兼容。主要支持的平台包括：
- **Raspberry Pi** 系列
- **Radxa** 系列
- **OpenIPC** 系列

## 3. 平台差异对比

### 3.1 系统架构

| 特性 | Raspberry Pi | Radxa | OpenIPC |
|------|-------------|-------|---------|
| CPU架构 | ARM (32/64位) | ARM64 (aarch64) | ARM (32位) |
| GPU | Broadcom VC | ARM Mali | 无/简单 |
| 操作系统 | Raspbian | Debian/Ubuntu | OpenIPC Linux |
| 内核 | Linux | Linux | Linux (精简) |

### 3.2 渲染后端

| 平台 | 渲染后端 | 底层库 | 说明 |
|------|----------|--------|------|
| Raspberry Pi | RenderEngineRaw | fbgraphics + Dispmanx | 使用 Broadcom GPU |
| Raspberry Pi | RenderEngineOVG | OpenVG | 矢量图形 |
| Radxa | RenderEngineCairo | Cairo + DRM | 使用 DRM/KMS |
| OpenIPC | 无SDL | - | 资源受限 |

### 3.3 GPIO库

| 平台 | GPIO库 | 说明 |
|------|--------|------|
| Raspberry Pi | wiringPi | 传统GPIO库 |
| Radxa | gpiod | 新版GPIO库 |
| OpenIPC | 无 | GPIO禁用 |

### 3.4 I2C库

| 平台 | I2C库 | 说明 |
|------|--------|------|
| Raspberry Pi | wiringPiI2C | wiringPi I2C扩展 |
| Radxa | libi2c | 独立I2C库 |
| OpenIPC | 无 | I2C禁用 |

### 3.5 视频捕获

| 平台 | 视频源 | 说明 |
|------|--------|------|
| Raspberry Pi | CSI + MMAL | 使用 Broadcom MMAL |
| Raspberry Pi | HDMI | HDMI输入捕获 |
| Radxa | CSI + Majestic | Majestic视频框架 |
| OpenIPC | CSI + Majestic | Majestic视频框架 |

### 3.6 摄像头支持

| 摄像头类型 | CAMERA_TYPE | 支持平台 |
|------------|-------------|----------|
| CSI摄像头 | `CAMERA_TYPE_CSI` (1) | Pi, Radxa, OpenIPC |
| VEye 290 | `CAMERA_TYPE_VEYE290` (3) | Pi |
| VEye 307 | `CAMERA_TYPE_VEYE307` (4) | Pi |
| VEye 327 | `CAMERA_TYPE_VEYE327` (5) | Pi |
| HDMI输入 | `CAMERA_TYPE_HDMI` (7) | Pi |
| IP摄像头 | `CAMERA_TYPE_IP` (8) | 所有 |
| OpenIPC IMX307 | `CAMERA_TYPE_OPENIPC_IMX307` (20) | OpenIPC |
| OpenIPC IMX335 | `CAMERA_TYPE_OPENIPC_IMX335` (21) | OpenIPC |
| OpenIPC IMX415 | `CAMERA_TYPE_OPENIPC_IMX415` (22) | OpenIPC |

## 4. 编译配置

### 4.1 Makefile 平台选择

```makefile
# Raspberry Pi (默认)
make all

# Radxa
make all RUBY_BUILD_ENV=radxa

# OpenIPC
make all RUBY_BUILD_ENV=openipc
```

### 4.2 编译宏定义

| 宏 | 平台 | 说明 |
|----|------|------|
| `RUBY_BUILD_HW_PLATFORM_PI` | Raspberry Pi | 树莓派平台 |
| `RUBY_BUILD_HW_PLATFORM_RADXA` | Radxa | Radxa平台 |
| `RUBY_BUILD_HW_PLATFORM_OPENIPC` | OpenIPC | OpenIPC平台 |

### 4.3 平台特定编译选项

```makefile
# Raspberry Pi
ifeq ($(RUBY_BUILD_ENV),)
_LDFLAGS := $(LDFLAGS) -lrt -lpcap -lpthread -lwiringPi -Wl,--gc-sections
_CFLAGS := $(_CFLAGS) -DRUBY_BUILD_HW_PLATFORM_PI
_CPPFLAGS := $(_CPPFLAGS) -DRUBY_BUILD_HW_PLATFORM_PI

LDFLAGS_CENTRAL := -L/usr/lib/arm-linux-gnueabihf -lopenmaxil -lbcm_host ...
LDFLAGS_RENDERER := -L../openvg -L/opt/vc/lib/ -lbrcmGLESv2 -lbrcmEGL ...

CENTRAL_RENDER_CODE := render_engine_raw.o fbg_dispmanx.o ...
endif

# Radxa
ifeq ($(RUBY_BUILD_ENV),radxa)
_LDFLAGS := $(LDFLAGS) -lrt -lpcap -lpthread -li2c -lgpiod -Wl,--gc-sections
_CFLAGS := $(_CFLAGS) -DRUBY_BUILD_HW_PLATFORM_RADXA
_CPPFLAGS := $(_CPPFLAGS) -DRUBY_BUILD_HW_PLATFORM_RADXA

LDFLAGS_CENTRAL := -L/lib/aarch64-linux-gnu -lpthread -lrt -lm
LDFLAGS_RENDERER := -ldrm -lcairo

CENTRAL_RENDER_CODE := render_engine_cairo.o drm_core.o ...
endif

# OpenIPC
ifeq ($(RUBY_BUILD_ENV),openipc)
_LDFLAGS := $(LDFLAGS) -lrt -lpcap -lpthread -Wl,--gc-sections
_CFLAGS := $(_CFLAGS) -DRUBY_BUILD_HW_PLATFORM_OPENIPC
_CPPFLAGS := $(_CPPFLAGS) -DRUBY_BUILD_HW_PLATFORM_OPENIPC

# 无SDL，无复杂渲染
endif
```

## 5. GPIO 引脚定义

### 5.1 Raspberry Pi GPIO

```c
// 按键引脚

#define GPIO_PIN_BACK 24      // 返回按钮
#define GPIO_PIN_PLUS 22      // 加按钮
#define GPIO_PIN_MINUS 27     // 减按钮

// 快捷动作引脚
#define GPIO_PIN_QACTION1 17  // 快捷动作1
#define GPIO_PIN_QACTION2 4   // 快捷动作2
#define GPIO_PIN_QACTION2_2 25 // 快捷动作2备用
#define GPIO_PIN_QACTION3 18  // 快捷动作3
#define GPIO_PIN_QACTIONPLUS 16  // 快捷加
#define GPIO_PIN_QACTIONMINUS 20 // 快捷减

// 类型检测引脚
#define GPIO_PIN_DETECT_TYPE_VEHICLE 19     // 车辆类型检测
#define GPIO_PIN_DETECT_TYPE_CONTROLLER 26  // 控制器类型检测

// LED和蜂鸣器
#define GPIO_PIN_LED_RED 5     // 红色LED
#define GPIO_PIN_LED_GREEN 21  // 绿色LED
#define GPIO_PIN_BUZZER 26     // 蜂鸣器
```

## 6. 硬件检测流程

### 6.1 板型检测

```c
void hardware_detectBoardAndSystemType()
{
    // 1. 检测 Raspberry Pi
    //    - 读取 /proc/cpuinfo
    //    - 解析 Revision 字段
    //    - 确定具体型号
    
    // 2. 检测 Radxa
    //    - 检查特定设备文件

    // 3. 检测 OpenIPC

}
```

## 11. 平台适配代码示例

### 11.1 平台检测代码

```c
u32 hardware_getBoardType()
{
    #ifdef RUBY_BUILD_HW_PLATFORM_PI
    return g_uBoardType;  // 运行时检测的具体Pi型号
    #endif
    
    #ifdef RUBY_BUILD_HW_PLATFORM_RADXA
    return g_uBoardType;  // 运行时检测的具体Radxa型号
    #endif
    
    #ifdef RUBY_BUILD_HW_PLATFORM_OPENIPC
    return g_uBoardType;  // 运行时检测的具体OpenIPC型号
    #endif
    
    return BOARD_TYPE_NONE;
}

int hardware_board_is_raspberry(u32 uBoardType)
{
    return (uBoardType >= BOARD_TYPE_PIZERO && uBoardType <= BOARD_TYPE_PI4B);
}

int hardware_board_is_radxa(u32 uBoardType)
{
    return (uBoardType >= BOARD_TYPE_RADXA_ZERO3 && uBoardType <= BOARD_TYPE_RADXA_RUNCAM_VRX);
}

int hardware_board_is_openipc(u32 uBoardType)
{
    return (uBoardType >= BOARD_TYPE_OPENIPC_GOKE200 && uBoardType <= BOARD_TYPE_OPENIPC_SIGMASTAR_338Q);
}
```

## 13. 平台选择建议

### 13.1 地面站推荐

| 场景 | 推荐平台 | 原因 |
|------|----------|------|
| 标准使用 | Raspberry Pi 4B | 性能强，显示好 |
| 便携使用 | Raspberry Pi Zero 2 W | 小巧，带WiFi |
| 高清显示 | Radxa 3C | 支持高分辨率 |

### 13.2 机载端推荐

| 场景 | 推荐平台 | 原因 |
|------|----------|------|
| 标准无人机 | OpenIPC AIO | 一体化，轻量 |
| 需要HDMI输出 | Raspberry Pi Zero 2 W | 支持HDMI |
| 高性能需求 | Radxa Zero 3 | 性能强 |

## 14. 平台适配开发指南

### 14.1 新平台适配步骤

1. **定义板型常量**
   - 在 `hardware.h` 中添加新的 `BOARD_TYPE`
   - 定义子型号（如有）

2. **添加编译宏**
   - 在 Makefile 中添加新的编译环境
   - 定义平台特定宏

3. **实现硬件检测**
   - 在 `hardware.cpp` 中添加检测逻辑
   - 识别新平台的方法

4. **实现GPIO适配**
   - 创建新的 GPIO 实现文件
   - 实现引脚初始化和操作

5. **实现渲染适配**
   - 选择合适的渲染后端
   - 或创建新的渲染实现

6. **实现视频源适配**
   - 选择或创建视频源实现
   - 支持平台摄像头

7. **测试验证**
   - 编译测试
   - 功能测试
   - 性能测试
