# RubyFPV 项目总体架构

## 1. 项目概述

### 1.1 项目简介

**RubyFPV** 是一个完整的开源数字 FPV（First Person View，第一人称视角）无线电系统解决方案，包含硬件和软件两部分。该系统专为无人机、遥控飞机、遥控车等远程车辆的控制和管理而设计，提供稳健的端到端数字无线电链路。

- **项目名称**: RubyFPV
- **当前版本**: 11.8 (Build 11801)
- **许可证**: Ruby Licence（开源，禁止军事用途）
- **官方网站**: https://rubyfpv.com/
- **开发者**: Petru Soroaga (petrusoroaga@yahoo.com)

### 1.2 核心特性

| 特性 | 描述 |
|------|------|
| **多频段冗余链路** | 支持 433/868/915 MHz 和 2.4/5.8 GHz 多个频段同时使用，提供更好的抗干扰能力和链路可靠性 |
| **中继功能** | 支持移动（车载）和固定中继节点，扩展通信范围，实现超视距通信 |
| **端到端加密** | 支持无线电链路端到端加密（当前版本暂时禁用） |
| **多数据流** | 同时支持视频、音频、遥测、遥控和用户自定义数据流 |
| **丰富用户界面** | 提供完整的图形化控制界面 |
| **插件SDK** | 提供公开SDK供第三方开发新功能 |

### 1.3 支持的硬件平台

| 平台 | 编译参数 | 说明 |
|------|----------|------|
| **Raspberry Pi** | `RUBY_BUILD_ENV=` (默认) | 树莓派平台，使用 OpenVG 渲染、wiringPi GPIO、MMAL 视频捕获 |
| **Radxa** | `RUBY_BUILD_ENV=radxa` | Radxa 单板机，使用 DRM/Cairo 渲染、SDL2、gpiod |
| **OpenIPC** | `RUBY_BUILD_ENV=openipc` | OpenIPC 嵌入式摄像头平台 |

### 3.2 模块职责

| 模块 | 职责 | 主要文件 |
|------|------|----------|
| **base** | 核心基础功能：配置管理、硬件抽象、GPIO控制、加密、工具函数 | `config.*`, `hardware.*`, `gpio.*`, `encr.*`, `utils.*` |

| **radio** | 无线电链路层：数据包处理、FEC纠错、收发控制 | `radiolink.*`, `radiopackets2.*`, `fec.*`, `radio_rx.*`, `radio_tx.*` |
| **r_central** | 地面站控制中心：UI界面、菜单、OSD、键盘输入、告警 | `ruby_central.*`, `menu/*`, `osd/*`, `keyboard.*`, `notifications.*` |

| **renderer** | 渲染引擎：支持多平台渲染 | `render_engine.*`, `render_engine_cairo.*`, `render_engine_raw.*` |
| **r_plugins_*** | 插件系统：OSD插件、核心插件 | 各插件目录 |

## 5. 编译与构建

### 5.1 构建命令

```bash
# Raspberry Pi 平台（默认）
make all

# Radxa 平台
make all RUBY_BUILD_ENV=radxa

# OpenIPC 平台
make all RUBY_BUILD_ENV=openipc

# 清理
make clean
```

### 5.2 编译宏定义

| 宏 | 平台 | 说明 |
|----|------|------|
| `RUBY_BUILD_HW_PLATFORM_PI` | Raspberry Pi | 树莓派平台 |
| `RUBY_BUILD_HW_PLATFORM_RADXA` | Radxa | Radxa 单板机 |
| `RUBY_BUILD_HW_PLATFORM_OPENIPC` | OpenIPC | OpenIPC 嵌入式平台 |

### 5.3 平台差异

| 特性 | Raspberry Pi | Radxa | OpenIPC |
|------|-------------|-------|---------|
| 渲染后端 | OpenVG/fbgraphics | DRM/Cairo | 无SDL |
| GPIO库 | wiringPi | gpiod | - |
| I2C库 | wiringPi | libi2c | - |
| 视频捕获 | MMAL/bcm_host | Majestic | Majestic |
| SDL | 可选 | SDL2 | 无 |

## 6. 进程架构

### 6.1 主要进程

| 进程 | 所属模块 | 功能 |
|------|----------|------|
| `ruby_central` | r_central | 地面站主控制程序 |
| `ruby_rt_vehicle` | r_vehicle | 机载端主程序 |
| `ruby_start` | r_start | 系统启动管理 |
| `ruby_player` | r_player | 视频播放器 |
| `ruby_i2c` | r_i2c | I2C 通信服务 |

### 6.2 进程间通信

- **共享内存 (Shared Memory)**: 用于大数据传输（视频流、遥测数据）
- **IPC 消息队列**: 用于命令和控制消息
- **信号量 (Semaphore)**: 用于同步
