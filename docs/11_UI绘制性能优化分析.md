# UI绘制性能优化分析 (Radxa Cairo引擎)

## 1. 问题概述

RubyFPV在Radxa设备上使用Cairo渲染引擎进行UI绘制。当前实现存在严重的性能问题，UI绘制在多处被反复调用和刷新，导致CPU开销过大。

### 1.1 性能指标

根据代码中的性能统计：
- **UI FPS**: 目标帧率，实际受渲染开销影响
- **Menu渲染时间**: `s_uMicroTimeMenuRender` (微秒/帧)
- **Popup渲染时间**: `s_uMicroTimePopupRender` (微秒/帧)
- **OSD渲染时间**: `s_uMicroTimeOSDRender` (微秒/帧)

## 3. Cairo引擎性能瓶颈

### 3.1 startFrame() 问题

```cpp
void RenderEngineCairo::startFrame()
{
   // 问题1: 每帧都销毁旧的Cairo context
   if ( NULL != m_pCairoCtx )
      cairo_destroy(m_pCairoCtx);
   m_pCairoCtx = NULL; 

   // 问题2: 每帧都清空整个缓冲区 (全屏清除)
   type_drm_buffer* pOutputBufferInfo = ruby_drm_core_get_back_draw_buffer();
   memset(pOutputBufferInfo->pData, m_uClearBufferByte, pOutputBufferInfo->uSize);
   
   // 问题3: 每帧都创建新的Cairo context
   if ( pOutputBufferInfo->uBufferId == m_uRenderDrawSurfacesIds[0] )
      m_pCairoCtx = cairo_create(m_pMainCairoSurface[0]);
   // ...
}
```

**性能开销**:
- `memset()` 清空1280x720x4字节 ≈ 3.7MB，耗时约1-2ms
- `cairo_create()` 创建context，耗时约0.5-1ms
- `cairo_destroy()` 销毁context，耗时约0.3-0.5ms

### 3.2 endFrame() 问题

## 6. 优化方案

### 6.1 脏区域追踪系统

**目标**: 只重绘发生变化的部分区域

```cpp
// 新增脏区域管理
typedef struct {
   float x, y, width, height;
   bool isDirty;
} DirtyRegion;

class RenderEngineCairoOptimized : public RenderEngineCairo
{
   private:
      DirtyRegion m_dirtyRegions[MAX_DIRTY_REGIONS];
      int m_dirtyRegionCount;
      bool m_fullRedrawNeeded;
      
   public:
      void markDirty(float x, float y, float w, float h);
      void clearDirtyRegions();
      bool needsRedraw(float x, float y, float w, float h);
};
```

**实现要点**:
1. 维护脏区域列表
2. 只清除脏区域而非全屏
3. 只重绘脏区域内的元素

### 6.2 Cairo Context复用

**目标**: 避免每帧创建/销毁Cairo context

```cpp
void RenderEngineCairo::startFrame()
{
   // 优化: 复用Cairo context
   if ( NULL == m_pCairoCtx )
   {
      type_drm_buffer* pOutputBufferInfo = ruby_drm_core_get_back_draw_buffer();
      if ( pOutputBufferInfo->uBufferId == m_uRenderDrawSurfacesIds[0] )
         m_pCairoCtx = cairo_create(m_pMainCairoSurface[0]);
      // ...
   }
   
   // 优化: 只清除脏区域
   if ( m_fullRedrawNeeded )
   {
      memset(pOutputBufferInfo->pData, m_uClearBufferByte, pOutputBufferInfo->uSize);
   }
   else
   {
      clearDirtyRegionsOnly();
   }
}

void RenderEngineCairo::endFrame()
{
   // 优化: 不销毁Cairo context，保留复用
   // cairo_destroy(m_pCairoCtx); // 移除
   
   ruby_drm_swap_mainback_buffers();
}
```

### 6.5 批量绘制优化

**目标**: 减少绘制调用次数

```cpp
// 优化drawRect: 使用批量填充
void RenderEngineCairo::drawRectOptimized(float xPos, float yPos, float fWidth, float fHeight)
{
   int xSt = xPos*m_iRenderWidth;
   int ySt = yPos*m_iRenderHeight;
   int w = fWidth*m_iRenderWidth;
   int h = fHeight*m_iRenderHeight;
   
   u32 uColor = (((u32)a) << 24) | (((u32)r) << 16) | (((u32)g) << 8) | ((u32)b);
```

### 6.6 渲染调度优化

**目标**: 统一渲染调度，避免重复渲染

```cpp
class RenderScheduler
{
   private:
      u32 m_lastRenderTime;
      u32 m_minRenderInterval;  // 最小渲染间隔 (ms)
      bool m_renderRequested;
      
   public:
      void requestRender();           // 请求渲染
      bool shouldRender();            // 是否应该渲染
      void executeRender();           // 执行渲染
};

// 统一渲染入口
void RenderScheduler::requestRender()
{
   m_renderRequested = true;
}

bool RenderScheduler::shouldRender()
{
   u32 now = get_current_timestamp_ms();
   if ( !m_renderRequested )
      return false;
   if ( now < m_lastRenderTime + m_minRenderInterval )
      return false;
   return true;
}

void RenderScheduler::executeRender()
{
   if ( shouldRender() )
   {
      render_all_with_menus(g_TimeNow, true, false, false);
      m_lastRenderTime = get_current_timestamp_ms();
      m_renderRequested = false;
   }
}
```

## 9. 代码修改建议

### 9.1 render_engine_cairo.cpp 修改

```cpp
// 1. 添加脏区域管理
#define MAX_DIRTY_REGIONS 32

typedef struct {
   float x, y, width, height;
} DirtyRegion;

static DirtyRegion s_dirtyRegions[MAX_DIRTY_REGIONS];
static int s_dirtyRegionCount = 0;
static bool s_fullRedraw = true;

// 2. 修改startFrame
void RenderEngineCairo::startFrame()
{
   RenderEngine::startFrame();

   // 复用Cairo context
   if ( NULL == m_pCairoCtx )
   {
      type_drm_buffer* pOutputBufferInfo = ruby_drm_core_get_back_draw_buffer();
      if ( pOutputBufferInfo->uBufferId == m_uRenderDrawSurfacesIds[0] )
         m_pCairoCtx = cairo_create(m_pMainCairoSurface[0]);
      // ...
   }

   // 只在需要时全屏清除
   if ( s_fullRedraw )
   {
      memset(pOutputBufferInfo->pData, m_uClearBufferByte, pOutputBufferInfo->uSize);
      s_fullRedraw = false;
   }
   else
   {
      // 只清除脏区域
      for( int i=0; i<s_dirtyRegionCount; i++ )
      {
         clearRegion(s_dirtyRegions[i]);
      }
   }
   
   s_dirtyRegionCount = 0;
}

// 3. 修改endFrame
void RenderEngineCairo::endFrame()
{
   // 不销毁Cairo context，保留复用
   // cairo_destroy(m_pCairoCtx); // 移除此行
   
   ruby_drm_swap_mainback_buffers();
   RenderEngine::endFrame();
}

// 4. 添加脏区域标记
void RenderEngineCairo::markDirty(float x, float y, float w, float h)
{
   if ( s_dirtyRegionCount < MAX_DIRTY_REGIONS )
   {
      s_dirtyRegions[s_dirtyRegionCount].x = x;
      s_dirtyRegions[s_dirtyRegionCount].y = y;
      s_dirtyRegions[s_dirtyRegionCount].width = w;
      s_dirtyRegions[s_dirtyRegionCount].height = h;
      s_dirtyRegionCount++;
   }
   else
   {
      s_fullRedraw = true;
   }
}
```

## 11. 总结

### 11.1 主要问题

1. **每帧全屏清除**: 浪费CPU和内存带宽
2. **Cairo context重复创建**: 不必要的开销
3. **OSD全量渲染**: 静态和动态元素都每帧重绘
4. **渲染调用分散**: 缺乏统一调度

### 11.2 优化方向

1. **脏区域追踪**: 只更新变化的部分
2. **Cairo context复用**: 避免重复创建
3. **OSD分层渲染**: 分离静态和动态层
4. **数值变化检测**: 只更新变化的数值
5. **统一渲染调度**: 避免重复渲染

### 11.3 预期效果

- 渲染时间减少 **60%**
- CPU使用率降低 **50%**
- 帧率稳定在 **60fps**
